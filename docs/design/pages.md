# Design Specification — Page Inventory

## Brief
Defines the first page set and its responsibility.

## Public/Marketing
- Landing page — product value and integrations.
- Pricing — plans, limits, and billing model.
- Integration catalog — discover supported sources.
- Integration detail — explain source capabilities and setup.
- Documentation — installation and usage guides.

## Auth
- Sign in.
- Sign up.
- Verify email.
- Forgot/reset password.

## Application
- Dashboard home — account/project overview.
- Projects — list and create projects.
- Project detail — widgets, sources, activity.
- Integrations/connections — connected providers and source status.
- Widget catalog — select app/widget type.
- Widget editor — configure and preview.
- Publish/install — embed code, share link, guides.
- Usage — views and resource consumption.
- Billing — subscription and invoices.
- Account settings — profile, security, preferences.

## Admin
- Users/accounts.
- Integrations.
- Jobs/sync health.
- Usage.
- Support/audit.
- Feature flags.

## Navigation Principle
A user should always understand:
1. Which project they are working in.
2. Which widget they are editing.
3. Whether changes are draft or published.
4. Whether the connected data source is healthy.
