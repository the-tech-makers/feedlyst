# Scope 05 — Phase 5: Usage, Plans & Billing

## Brief
Introduce monetization without coupling billing logic to individual widgets.

## Module 5.1 — Usage Metering
Track:
- widget views;
- active widgets;
- projects;
- connected sources;
- synchronization usage;
- storage where applicable.

A view represents a widget load on a webpage, consistent with the reference SaaS model. citeturn0search0

## Module 5.2 — Plans
Initial plan dimensions:
- views/month;
- widgets;
- projects;
- integrations;
- advanced customization;
- branding;
- support level.

## Module 5.3 — Billing
- Subscription creation.
- Upgrade/downgrade.
- Trial handling.
- Payment provider integration.
- Invoice/customer portal.
- Webhook processing.
- Subscription state reconciliation.

## Module 5.4 — Limits
- Soft warnings.
- Hard limits.
- Grace periods where appropriate.
- Safe behavior when limits are exceeded.
- Admin override for support.

## Acceptance
Usage is attributable to a tenant and plan limits are enforced consistently across dashboard and public delivery.
