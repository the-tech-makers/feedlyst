# Scope 04 — Phase 4: Publishing & Delivery

## Brief
Turn a configured widget into a stable public asset that can be embedded on external websites.

## Module 4.1 — Publication
- Publish/unpublish.
- Stable widget identifier.
- Active configuration version.
- Publication status.
- Last published timestamp.

## Module 4.2 — Embed Runtime
Primary delivery:
- asynchronous JavaScript loader;
- target container;
- widget bootstrap;
- configuration retrieval;
- rendered output.

Secondary delivery:
- share URL;
- iframe-compatible mode where appropriate.

## Module 4.3 — Installation Guides
Provide concise instructions for:
- plain HTML;
- WordPress;
- Shopify;
- Webflow;
- Wix;
- Squarespace;
- Google Tag Manager.

Platform-specific guidance should reflect actual platform limitations rather than assuming all support arbitrary JavaScript. Elfsight similarly provides platform-specific installation paths. citeturn1search0turn1search4turn1search5

## Module 4.4 — Domain Controls
- Optional allowed-domain list.
- Origin validation.
- Unknown-domain behavior.
- Development/test domain support.

## Module 4.5 — Delivery Reliability
- CDN caching.
- Versioned assets.
- Failure fallback.
- Timeouts.
- Observability.

## Acceptance
A published widget can be installed on an external site using copied code and remains functional when the dashboard is not open.
