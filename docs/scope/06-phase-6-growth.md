# Scope 06 — Phase 6: Growth & Enterprise

## Brief
Expand Feedlyst from an MVP into an agency-ready platform.

## Module 6.1 — Integrations
Priority candidates:
- Instagram Feed.
- Facebook.
- Yelp.
- Google Business/Reviews extensions.
- YouTube.
- TikTok.
- X.
- RSS/Atom.
- Custom JSON/API source.

The product should be able to support many apps/integrations without changing the core dashboard architecture. Elfsight's current catalog demonstrates the breadth possible with this model. citeturn0search1

## Module 6.2 — Collaboration
- Project members.
- Roles and permissions.
- Invitations.
- Activity/audit log.
- Ownership transfer.

## Module 6.3 — Analytics
- Views.
- Unique sites/domains where measurable.
- Widget performance.
- Error rate.
- Sync health.
- Usage trends.

## Module 6.4 — Agency Features
- Client/project organization.
- White-label options.
- Shared templates.
- Bulk operations.
- Multiple installation environments.

## Module 6.5 — Enterprise
- SSO/SAML.
- SCIM.
- Advanced audit logs.
- SLA/priority support.
- Custom limits.
- Data retention controls.

## Acceptance
Growth capabilities can be enabled progressively without redesigning the MVP data model.
