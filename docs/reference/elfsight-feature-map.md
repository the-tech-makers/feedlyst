# Reference — Elfsight Feature Map

## Brief
A competitive/product-reference document used to identify proven workflow patterns. It is not a commitment to reproduce every feature.

## Observed Patterns
- Dashboard separates My Apps, Projects, Apps Catalog, and Templates.
- Projects group widgets for multi-site/client workflows.
- Widgets can be autosaved as drafts and explicitly published.
- Installation supports embed code and, for supported widgets, share links.
- View limits and usage statistics are surfaced in the dashboard.
- Team and project-level collaboration are supported on applicable plans.
- Widget editors expose layout-specific controls and appearance customization.
- Display behavior can include page/device/audience/schedule rules for applicable widgets.
- Platform-specific installation guidance is provided for different website builders.

## Feedlyst Interpretation
MVP should implement the underlying product architecture, not the full breadth:
- Projects: MVP.
- Widget catalog/templates: MVP at small scale.
- Autosave + publish: MVP.
- Embed code: MVP.
- Share URL: Phase 4.
- Usage tracking: Phase 5.
- Collaboration: Phase 6.
- Advanced display rules: Phase 6 unless required by a specific widget.
- Large app catalog: post-MVP.
